## Description

**ft_printf** is a 42 project where you recode the standard `printf` function. It teaches how to use **variadic functions** (`va_list`), how to parse a format string, and how to organize a clean and extensible code base.

The result is a static library, `libftprintf.a`, that can be linked into other projects.

```c
int ft_printf(const char *format, ...);
```

It returns the number of characters printed, like the original `printf`.

## Installation

```bash
git clone https://github.com/mohamedzeouaoui/ft_printf.git
cd ft_printf
make
```

This produces the static library `libftprintf.a`.

### Makefile rules

| Rule          | Description                                    |
|---------------|------------------------------------------------|
| `make`        | Build `libftprintf.a`                          |
| `make bonus`  | Build with the bonus features (if implemented) |
| `make clean`  | Remove object files                            |
| `make fclean` | Remove object files and `libftprintf.a`        |
| `make re`     | Recompile from scratch                         |

## Usage

Include the header and link the library:

```c
#include "ft_printf.h"

int main(void)
{
    int count;

    count = ft_printf("Hello %s, you are %d years old!\n", "42", 42);
    ft_printf("Printed %d characters\n", count);
    return (0);
}
```

```bash
cc -Wall -Wextra -Werror main.c -L. -lftprintf -o my_program
./my_program
```

## Supported Conversions

| Conversion | Description                                       | Example                      |
|------------|---------------------------------------------------|------------------------------|
| `%c`       | A single character                                | `ft_printf("%c", 'A')`       |
| `%s`       | A string (prints `(null)` for a `NULL` pointer)   | `ft_printf("%s", "hello")`   |
| `%p`       | A pointer in hexadecimal                          | `ft_printf("%p", ptr)`       |
| `%d`       | A signed decimal integer                          | `ft_printf("%d", -42)`       |
| `%i`       | A signed integer (same as `%d`)                   | `ft_printf("%i", 42)`        |
| `%u`       | An unsigned decimal integer                       | `ft_printf("%u", 3000000000)`|
| `%x`       | An unsigned hexadecimal number, lowercase         | `ft_printf("%x", 255)`       |
| `%X`       | An unsigned hexadecimal number, uppercase         | `ft_printf("%X", 255)`       |
| `%%`       | A literal percent sign                            | `ft_printf("%%")`            |

## How It Works

1. **Start**: `va_start` initializes the argument list from the last named parameter.
2. **Read the format string**: the function walks through it character by character.
3. **Normal characters**: they are written directly with `write`.
4. **Conversions**: when a `%` is found, the next character selects the conversion, and the matching function takes the next argument with `va_arg`.
5. **Count**: every function returns the number of characters it wrote, and the total is accumulated.
6. **End**: `va_end` cleans up, and the total is returned.

Number conversions use a recursive approach, or a buffer, to print digits in the right order in any base (10 for decimals, 16 for hexadecimal).

## Testing

Compare your output with the real `printf`, including the return value:

```c
int a = ft_printf("%s|%d|%x|%p\n", "test", -42, 255, &a);
int b =    printf("%s|%d|%x|%p\n", "test", -42, 255, &a);
// a and b must be equal, and both lines identical
```

Edge cases worth testing:

- `%s` with `NULL`, and an empty string
- `%p` with `NULL` (`(nil)` on Linux, `0x0` on macOS)
- `%d` and `%i` with `INT_MIN` and `INT_MAX`
- `%u` with `-1`, and `%x` with `0` and `-1`
- `%c` with `0` (the null character counts as one printed character)
- `%%` and a string ending with a lone `%`
- A format with many conversions in a row
